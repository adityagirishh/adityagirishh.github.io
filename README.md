# Aditya Girish Portfolio

Modern dark portfolio for GitHub Pages built with React + Vite + Tailwind CSS.

## Local run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
This repo is set up to deploy with GitHub Actions to:

`https://adityagirishh.github.io/`

Steps:
1. Create a GitHub repo named `adityagirishh.github.io` under the `adityagirishh` account.
2. Push this project to the `main` branch of that repo.
3. In GitHub, open **Settings -> Pages** and set **Source** to **GitHub Actions**.
4. Make sure your resume is present at `public/resume.pdf`.
5. Push any new commit to `main`, or run the **Deploy to GitHub Pages** workflow manually from the **Actions** tab.
